# 🛡️ AegisSQL Sentinel
### AI-Powered SQL Injection Defense & Cybersecurity Learning Platform

**AegisSQL Sentinel** is an AI-powered cybersecurity platform designed to detect, analyze, and prevent SQL Injection (SQLi) and Cross-Site Scripting (XSS) attacks using a combination of rule-based detection, security signatures, and AI-assisted analysis.

It also provides an interactive cybersecurity learning environment where users can understand attack patterns, analyze suspicious inputs, monitor security incidents, and learn defensive security techniques.

---

## 🚀 Key Features

### 1. Target Authentication Portal & Alert System
- Interactive authentication portal.
- Detects suspicious login inputs.
- Identifies potential SQL Injection attempts.
- Displays security alerts for suspicious activity.
- Demonstrates secure authentication concepts.

### 2. Autonomous Retraining Lab
- Cybersecurity learning and intelligence dashboard.
- Displays security signatures and detection statistics.
- Supports security-rule updates.
- Provides a foundation for adaptive threat detection.

### 3. Global Threat Feeds
- Displays cybersecurity threat intelligence.
- Organizes security information by categories.
- Supports CVE and security advisory exploration.
- Provides a centralized threat intelligence interface.

### 4. Payload Injection & AST Workbench
- Analyzes submitted input strings.
- Performs lexical and syntax analysis.
- Identifies suspicious SQL patterns.
- Provides AI-assisted security analysis.
- Helps understand how SQL injection vulnerabilities occur.

### 5. Intercepted Incident Log
- Displays detected security incidents.
- Maintains a chronological incident history.
- Shows threat classifications and severity.
- Supports incident inspection and audit-log export.

### 6. Network Port & Service Scanner
- Nmap-based network scanning interface.
- Helps identify exposed network services.
- Displays service and port information.
- Supports authorized network security assessments.

### 7. AI Security Assistant
- AI-assisted cybersecurity explanations.
- Helps understand security vulnerabilities.
- Provides defensive security recommendations.
- Supports cybersecurity learning.

### 8. Presentation Generator
- Generates cybersecurity presentation content.
- Helps explain SQL Injection concepts.
- Supports security awareness and learning.

## ⚙️ Installation & Setup

### Prerequisites

- Node.js
- Bun
- Git
- Gemini API key (if AI features require it)
- Nmap (if network scanning integration is enabled)

### Step 1: Clone the Repository

```bash
git clone https://github.com/sagarhd2/payload_detection.git
```

### Step 2: Navigate to the Project

```bash
cd payload_detection
```

### Step 3: Install Dependencies

```bash
bun install
```

### Step 4: Configure Environment Variables

Create a `.env` file using `.env.example` as a reference.

Add the required API keys and configuration values.

**Important:** Never upload API keys, passwords, or secret credentials to GitHub.

### Step 5: Start the Application

Check the available scripts in `package.json` and run the appropriate development command.

For example:

```bash
bun run dev
```
